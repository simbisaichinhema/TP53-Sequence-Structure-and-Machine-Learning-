Model

Model information

Algorithm
Random forest (400 trees, balanced weights)
Held-out performance
F1 0.880 · ROC-AUC 0.937 · acc 0.846 (n = 78)
Training data
388 ClinVar variants (232 pathogenic / 156 benign)
Target
Germline classification (1 = P/LP, 0 = B/LB; VUS excluded)

Features (21): protein position, UniProt domain, distance to zinc ligands, Grantham-1974 distance, hydropathy / volume / charge / polarity deltas, WT-residue context, AlphaFold WT pLDDT at the site (±5 window), literature DNA-contact flag. Stratified 80/20 split, seed 42; scaling fit on train only.

Disclaimer. This is an academic research prototype trained on curated ClinVar annotations (n = 388). It is not a clinical diagnostic tool and must not guide medical decisions.
