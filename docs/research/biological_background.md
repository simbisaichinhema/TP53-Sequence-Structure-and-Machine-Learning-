# Biological background: TP53

- TP53 encodes tumor protein p53, a sequence-specific transcription factor
  regulating cell-cycle arrest, apoptosis, senescence, and DNA repair.
- Canonical isoform: 393 aa (UniProt P04637). Domain architecture:
  N-terminal transactivation domain (largely disordered), proline-rich region,
  central DNA-binding / core domain (~residues 94–292, structured, hotspot for
  cancer-associated missense variants such as R175H, R248Q/W, R273H),
  tetramerisation domain, C-terminal regulatory region (disordered).
- Most experimentally determined TP53 structures (e.g. PDB 2OCJ) cover the
  core domain only — never treat them as full-length references.
- AlphaFold predicts full-length chains including disordered termini; low
  pLDDT in terminal regions is expected and reflects disorder, not necessarily
  model failure. The confidence summaries in this project report
  fraction_disordered = 0.5, consistent with this biology.
- Language rule: variant annotations describe curated clinical/functional
  evidence; structural deviation alone never establishes pathogenicity,
  loss/gain of function, or causality.
